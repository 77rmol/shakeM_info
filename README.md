# Protein Shake Machine Landing

Landing estática creada a partir del contenido de `/Users/moro7/Downloads/Modelo de Negocio.pptx`.

## Archivos

- `index.html`: estructura principal de la home.
- `styles.css`: identidad visual, layout, motion y responsive.
- `script.js`: scroll-scrubbing del hero, reveals y contadores.
- `assets/images/`: imágenes extraídas del deck original.
- `assets/videos/machine-scroll.mp4`: video opcional para el hero.

## Cómo usarla

1. Abre `index.html` en el navegador o levanta un servidor estático simple.
2. Si quieres el efecto completo del hero, agrega tu video en:

```text
assets/videos/machine-scroll.mp4
```

3. El video se controla con el scroll:
   - si haces scroll hacia abajo, avanza;
   - si haces scroll hacia arriba, retrocede;
   - si no hay video, queda el fallback visual con la imagen de la máquina.

## Siguiente mejora recomendada

Reemplazar el video placeholder por una toma real de la máquina con fondo limpio, movimiento lento y duración entre 6 y 12 segundos para que el scrubbing se sienta más cinematográfico.
